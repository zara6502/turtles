### **Запуск**

Распаковать архив в корень репозитория, затем из MSYS2:

**Пилот — 20 лабиринтов 51×51:**

```
bash temp/src/run_maze_automata_sweep.sh --seed-from 1 --seed-to 5 --sizes 51x51
```

**60 лабиринтов всех трёх размеров:**

```
bash temp/src/run_maze_automata_sweep.sh --seed-from 1 --seed-to 5
```

**Полная выборка — 600 лабиринтов:**

```
bash temp/src/run_maze_automata_sweep.sh
```

По умолчанию A\* получает до 2 млн состояний и до 10 минут поиска на лабиринт. BFS удалён из этой версии.

### **Результаты**

Появятся в `temp/automata_sweep/`:

- `mazes/` — сами сгенерированные лабиринты;
- `astar_runs.csv` — результаты каждого прогона;
- `summary.txt` — статистика;
- `errors.log` — ошибки и тайм-ауты.

**Важное уточнение:** это новый детерминированный корпус с генерацией DFS и braiding. Он не побайтно совпадает с предыдущими 600 лабиринтами — их исходных файлов в репозитории нет.

Контрольный запуск 21×21 прошёл: DAFds — 308 команд, A\* — 138, оптимальность подтверждена.
