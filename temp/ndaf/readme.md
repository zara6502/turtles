### **Что реализовано**

1. **DAFds** — независимая контрольная реализация с лимитом стагнации 5 и Farthest fallback.
2. **Парный автомат** — вычисляет минимальную длину общей последовательности команд для каждой пары клеток.
3. **A\*** — поиск по множествам активных позиций с эвристикой парного автомата.
4. **BFS** — точный перебор множеств для проверки оптимальности.

A\* использует допустимую нижнюю оценку, а результат DAFds — как верхнюю границу. Поэтому статус `OPTIMAL` означает доказанную оптимальность, а не просто найденное хорошее решение.

### **Проверка на тестовом лабиринте**

8×8, 25 свободных клеток

| Алгоритм             | Команды | Просмотрено состояний |
| -------------------- | ------- | --------------------- |
| DAFds                | 21      | —                     |
| Парная нижняя оценка | 13      | —                     |
| A\*                  | **15**  | 55                    |
| BFS                  | **15**  | 48 910                |

A\* и BFS совпали

Оба нашли оптимальное решение на 6 команд короче DAFds.

### **Сборка в MSYS2 UCRT64**

```
g++ -std=c++17 -O3 -DNDEBUG -Wall -Wextra -Wpedantic maze_automata.cpp -o maze_automata.exe
```

Запуск:

```
./maze_automata.exe --maze maze_automata_example.txt --algo all --print-path
```

**Важное замечание:** пока это отдельный стенд с ASCII-входом, а DAFds в нём — порт по согласованным ранее правилам, не подключение к твоему существующему бинарнику. Проверка на 100 случайных небольших лабиринтах прошла под ASan/UBSan; там, где BFS завершался, его результат совпадал с A\*.

Сначала стоит проверить локальную сборку и несколько твоих лабиринтов. Затем перенесём автоматный поиск непосредственно в существующий benchmark, чтобы сравнения проводились на одной и той же выборке.
